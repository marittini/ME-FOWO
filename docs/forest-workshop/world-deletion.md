# 기존 세계 삭제

설정 → 저장·백업 → 다른 세계의 목록에서 각 세계의 삭제 버튼을 누른다. 읽을 수 없는 이전 데이터에도 삭제 버튼이 제공된다. 확인창에 대상 세계 이름과 삭제 범위를 표시하며 취소할 수 있다. 삭제 요청이 실패하면 해당 창에서 오류를 표시하고 재시도할 수 있다.

선택한 세계의 패키지 저장 문서와 명령·탐험 이야기·보관 기록을 삭제한다. 다른 세계, 원본 캐릭터·페르소나 카드, 공용 갤러리 이미지, 사용자가 내보낸 백업 파일은 삭제하지 않는다. 삭제 세계의 UUID만 담은 작은 삭제 표식을 남겨 늦게 도착한 생성·저장 재시도가 세계를 되살리지 못하게 한다. 백업에서 별도 세계로 복원할 수 있다.

현재 열린 세계를 삭제하면 선택을 해제하고 세계 목록으로 돌아간다. 다른 세계 삭제는 열린 세계를 유지한다. 삭제로 마지막 페이지가 비면 페이지 번호를 조정한다.

검증은 세계 삭제 서버 회귀·세계 목록 브라우저·삭제 컨트롤러 회귀 및 해당 패키지 타입/번들 무결성으로 한정한다. 결과는 아래에 기록한다. 실제 사용자 세계를 테스트 삭제하지 않는다.

## 검증 결과

- 서버 직접 회귀 통과: 읽을 수 없는 세계 삭제, 반복 삭제, 다른 세계·다른 패키지 보존, 생성과 삭제의 경쟁 시 생성 문서 정리, revision 불일치 시 삭제 표식까지 롤백, 삭제 후 세계 재생성·이야기 저장 차단.
- worlds 브라우저 통과: 세계별 삭제 버튼, 이름을 표시하는 확인창, 취소, 320px 확인창 범위·버튼 배치. 실제 패키지 종이·버튼 에셋을 제공한 화면을 /tmp/fw-world-delete.png에서 확인했다.
- 실제 컨트롤러를 같은 브라우저에 로드해 현재 세계 선택 해제 및 마지막 선택 저장 제거, 다른 세계 보존, 실패 시 기존 세계 유지, 삭제 후 도착한 이전 열기 응답 차단을 확인했다. 테스트 Engine API 모듈을 사용하며 실제 사용자 세계를 건드리지 않았다.
- 해당 패키지 엄격 타입 검사: 서버 88개·클라이언트 73개 파일 통과. 변경 파일 포맷·린트 및 재생성된 0.9.2 ZIP·카탈로그 해시·레인·릴리스 노트 검증 통과.

별도 전체 게임 회귀를 반복하지 않았다. Android 실기기와 실제 Engine 설치/업데이트는 이번 검증 범위에 포함하지 않았다. PR #31이 아직 병합되지 않아 같은 0.9.2 번들을 갱신한다.
