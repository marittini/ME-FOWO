# 0.9.1 홈 주민 크기와 이동 범위 고정

기준: PR #29가 병합된 main 4b32753a5. 표시 인원은 주민의 선택 수만 바꾼다. 1~6명 모두 기존 기본 크기 8.5em × 11em과 같은 이동 경로 범위를 사용한다. 지면 설정의 저장 영역과 초상 배치 설정은 유지한다. 인원이 많다는 이유로 자동 축소하거나 좁은 슬롯에 가두지 않는다. 서로 겹치는 것은 허용하며 기존 주민별 위상 차이로 위치가 분산된다.

저비용 gpt-6-luna에 CSS 수정과 인원별 브라우저 검증을 분담한다. 사용자 지시에 따라 검증은 홈 인원/크기/경로, 기존 보행·터치·모션 줄이기, 지면 편집 및 설치 번들 무결성에 한정한다. 전체 게임 회귀·523건 화면 검증은 반복하지 않는다.

검증 결과: 실제 CSS를 적용한 브라우저에서 1~6명의 폭·높이, 지면 사각형, 같은 시점의 발 좌표 경로가 같음을 확인했다. 변경한 지면 설정(8/92/45/95%) 안에서도 X/Y 이동과 경계, 편집 중 일시 정지·모션 줄이기가 유지된다. 기존 홈 보행·터치 검사에서 게시판이 겹쳤을 때 주민 입력이 우선하도록 주민 레이어를 보완하고 해당 히트 테스트를 통과했다.

수동 실행 범위는 home-cast / home-motion / ground의 브라우저 검사 3개와 변경 파일 포맷·린트, 설치 ZIP·카탈로그 해시다. 백엔드 게임 로직과 저장 스키마는 변경하지 않았다. 0.9.1 소스·생성 번들·ZIP·카탈로그·릴리스 노트를 함께 반영한다. 전체 게임 회귀나 전체 화면 검사를 실행했다는 의미는 아니다. Android 실기기는 미검증이다.
