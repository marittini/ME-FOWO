# 0.8.2 편지 경험 후속 작업

기준: main `0627f9c23032a5d6ba899d47cdd0d7a40cbc4cc4` (PR #27 병합 이후).

우선 범위: 편지 생성의 남은 실패 경로를 재현하고, 실패한 편지에서 연결 선택→재시도로 돌아오는 동선을 줄인다. 편지에 사용하는 공방 프로필·관계·기억의 맥락을 점검해 보고서 형태를 줄인다. 기존 우편 원문·설정·보관 상태는 유지한다.

낮은 비용의 서브에이전트 두 명이 서버/프롬프트와 클라이언트 동선을 각각 읽기 전용 점검한다. 주 에이전트가 수정·통합·실제 실행 검증을 담당한다.

사용자 외부 모델/실기기 검증과 격리된 Engine/시험 모델 검증은 구분하여 기록한다. 현재 외부 모델명·실패 문구·접속 주소는 확인 대기 중이다. 저장소 Issues는 비활성화되어 PR과 이 문서에서 범위를 추적한다.
