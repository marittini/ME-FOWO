# Forest Workshop 0.8.2 — 편지 복구·개인 맥락과 조작 피드백

기준 main: `0627f9c23032a5d6ba899d47cdd0d7a40cbc4cc4` (PR #27 병합 이후). 작업 PR #28. 검증일 2026-11-04.

## 이번 업데이트의 범위

사용자 확인에 따라 0.8.1 설치 후에도 같은 오류가 계속된다고 가정하지 않는다. 후속 업데이트에서 편지 복구 동선과 개인 맥락을 보완하고, 생산 대기·주민 터치의 즉각적인 피드백을 개선한다. 실제 외부 모델 오류 재현이나 문장 품질 검증과 로컬 시험 응답 검증을 구분한다.

낮은 비용 모델 `gpt-6-luna` 서브에이전트가 서버/프롬프트와 클라이언트를 분리 조사하고 프롬프트·생산 바로가기·홈 터치 반응의 작은 변경을 분담했다. 주 에이전트가 실패한 테스트를 수정하고 서버 맥락 전달·모델 선택 UI·통합 검증·번들 배포를 맡았다. 서브에이전트의 판단을 검증 결과로 대신하지 않는다.

## 실제로 재현한 복구 동선 문제

0.8.1 실제 Engine에서 레거시 주민의 설정용 연결만 사용할 수 없게 했다. 편지 모델은 정상이어도 `profiles.ensure()`가 먼저 실패한다. 응답은 구분 없는 `lm_unavailable`이며 우편에서는 편지 모델 설정으로 이동한다. 편지 연결만 변경해서는 이 오류를 해결할 수 없다.

0.8.2에서는 이 실패에 `details: { stage: "profile", purpose: "profile" }`를 반환한다. 우편 안의 **주민 설정 연결 확인**을 펼치면 해당 연결만 선택할 수 있다. 일반 편지 실패에는 **편지 모델 설정**이 표시된다. 선택 후 같은 우편에서 **편지 다시 불러오기**를 누른다. 다른 기능의 연결·선택한 우편·원본 활동은 유지한다. 선택만으로 모델을 호출하지 않으며 닫거나 다른 편지를 선택하면 도착한 편지를 강제로 열거나 읽음 처리하지 않는 기존 보호도 유지한다.

설정 화면과 우편은 동일한 모델 연결 선택 컴포넌트를 사용한다. 저장 실패 안내, 사라진 연결 표시, 엔진 기본 연결 선택은 그대로 지원한다. 연결의 출력·문맥 수치를 편집하는 엔진 설정 자체를 이 우편에 복제하지는 않았다.

## 편지 내용의 입력 계약

- 공방 프로필을 유일한 인물 설정으로 유지한다. 원본 세계관이나 설정을 다시 섞지 않는다.
- 플레이어 닉네임과 주민의 비연애 친밀도를 전달한다. 점수 자체를 본문에 출력하거나 연애로 단정하지 않는다.
- 주민이 아는 활성 기억만 전달하고 `event / feeling / player` 종류를 유지한다. 느낌을 객관적 사건이나 타인의 마음으로 확정하지 않도록 지시한다.
- 같은 주민의 저장된 최근 편지 최대 두 통을 문체 반복을 줄이는 참고자료로 전달한다. 다른 주민의 편지는 전달하지 않으며 이전 AI 문장을 새로운 사실의 근거로 삼지 않는다.
- 문맥이 부족하면 선택적인 이전 편지 참고부터 제외한다. 공방 프로필이나 기억 원문은 자동으로 잘라 쓰지 않으며, 그래도 맞지 않으면 저장 원문을 보존하고 안내한다.
- 활동 사실 하나에 대한 주민 자신의 반응을 수신자에게 직접 전하도록 지침을 보완했다. 정형 총평과 지어낸 보상·재화·과거 사건은 금지한다. 기존 편지를 덮어쓰거나 자동 추가 재생성하지 않는다.

이 계약과 입력 분리는 회귀로 검증한다. 실제 외부 모델의 자연스러움·개성·환각 방지는 코드 테스트만으로 보장하지 않는다. 짧은 출력이라는 이유만으로 새 실패를 만들지 않도록 기존 파싱 길이 범위는 유지했다.

## 생산과 주민 피드백

목표 재고를 채워 쉬는 시설에 **목표 재고 바꾸기**를 제공한다. 대기열이 비어 있는 이전 상태에도 생산 설정 바로가기가 있다. 재료 부족 시 재료를 얻을 시설로 가는 기존 동선과 재고 보호 규칙은 유지한다.

홈 주민 터치는 즉시 짧은 몸의 눌림·펴짐과 기존 감정표현으로 응답한다. 걷는 위치·좌우 방향과 이름표 없는 표시를 유지하고, 짧은 반응이 끝나면 보행 애니메이션으로 돌아간다. 모션 줄이기 설정에서는 몸 애니메이션을 끈다. 이 반응은 시각적 피드백이며 AI 대화·주민 간 관계 이벤트·친밀도 보상으로 가장하지 않는다.

## 검증 기록

- 회귀 22개 스위트: 개인 맥락, 기억의 비밀/상태/종류, 같은 주민의 이전 편지만 선택, 선택 참고의 문맥 초과 처리, 프로필 실패 목적, 기존 우편/보관/추가 호출 보호 포함.
- 엄격 타입 검사 서버 87개·클라이언트 72개 파일 통과. 포맷·린트 통과.
- 레이아웃 483건(14개 경로·96개 상태) 통과. 편지/주민 설정 연결 선택을 펼친 상태와 320×640 큰 글자, 390×844, 긴 화면, 가로 및 데스크톱 포함.
- 홈 터치의 실제 transform 변형과 0초 시작 지연, 보행 복귀, 모션 줄이기를 검사했다. 보행의 -4초 지연이 반응에도 상속되어 건너뛰던 CSS 우선순위 문제를 회귀로 잡아 수정했다.
- 브라우저: 같은 우편에서 올바른 연결 선택·다른 목적 연결 유지, 명시적 재시도, 생산 대기 바로가기, 기존 홈 보행/모션 줄이기 검증.
- 실제 Engine 2.5.1 + 로컬 OpenAI 호환 시험 서버: 동일 레거시 프로필 실패의 목적 구분 → 우편 내 설정용 연결 선택 → 프로필 한 번 준비 → 편지 한 번 생성 → 재열기 시 추가 호출 없음. 생산 수량 입력·현황 전환, 주민 팝업 중앙 및 무료 초대권 버튼 위치 유지도 확인했다.
- 새 활동의 정상 JSON 코드블록 생성, 200칸 우편함에서 다른 199개 원문·보관 상태 유지, 실제 백업/복원 확인.
- 0.8.2 ZIP은 빌더로 생성한다. v2/v3/레거시 카탈로그, 로케일, 릴리스 노트, ZIP/manifest SHA-256·바이트 검증 통과.

## 미검증과 다음 작업

외부 사용자 모델과 Android 실기기/PWA는 검증하지 않았다. ZIP은 격리 설치 fixture로 엔진에 배치했으며 원격 카탈로그 UI 설치·업데이트·제거는 미검증이다. Engine 체크아웃은 버전 2.5.1, `b8bf28382b740cac77f310df442f98c493166f43`이며 manifest 호환 기준 `7f341f9186db8e08f21d63cc47ec458deff250d5`는 유지한다. 저장 스키마·권한·보상 규칙·기존 편지는 변경하지 않았다. main 반영은 PR 병합 이후다.

다음 별도 범위는 주민 간 자발적 상호작용과 실제 AI 편지의 말투 품질 평가다. 특히 이번 터치 반응을 주민끼리 대화하거나 교류하는 기능으로 보고하지 않는다. 실제 모델을 연결할 수 있는 환경에서 대비되는 주민 두 명, 낮은/높은 친밀도, 기억 없음/있음 조건을 비교하고 말투·호칭·반복·미확정 감정의 단정을 사람이 읽어 평가해야 한다. 모델에 장문 설정이 들어갈 때 응답 지연과 출력 한도도 함께 기록한다.
