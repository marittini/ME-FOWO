# 0.7.1 — 선택 지역의 시간·계절·날씨

기준: 원격 main `cabd30650` (PR #24 병합 이후). 별도 worktree/브랜치에서 작업했으며 이전 편지·활동 저장소 작업은 포함하지 않는다.

## 동작

- 기존 설정의 도시 선택과 Open-Meteo 현재 날씨 연동을 재사용한다. 새 위치 권한·GPS·API 키는 필요하지 않다.
- 선택 도시의 IANA 시간대에 따른 현지 날짜로 자동 계절을 계산한다. 남반구는 계절을 반전하고 기존 수동 계절 선택은 유지한다.
- 날씨 응답에 해당 지역의 일출·일몰을 함께 받는다. 일출부터 일몰 직전까지 낮이며 나머지는 밤이다. 밤에는 홈 배경·주민의 밝기를 낮추고 맑은 하늘의 태양을 달로 바꾼다.
- 기존 화면 타이머가 계절·낮밤 경계만 감지하여 화면 갱신을 알린다. 터치나 생산 결과 변경이 필요하지 않으며 매초 전체 화면을 다시 그리지 않는다.
- 일출·일몰이 없거나 날짜가 지난 경우 현지 06–18시를 낮으로 사용한다. 날씨 조회는 기존 15분 캐시·요청 병합·실패 안내를 유지한다.
- 홈에는 온도·날씨를 표시한다. 선택 지역명은 설정에서 확인하며 홈 문구와 접근성 이름에는 노출하지 않는다.
- 생산량, 보상, 서버 UTC 일일 기준, 저장 스키마 및 기존 기능은 바꾸지 않는다.

## 검증

- `npm run test:forest-workshop`: 기존 20개 회귀 스위트 통과. 추가 경계값: 서울/뉴욕의 같은 순간 다른 달, 시드니의 남반구 여름, 현지 자정, 정확한 일출·일몰 경계, 지난 날짜의 일출·일몰 대체 처리, 도시 허용 목록과 캐시.
- ME-personal 기반 엄격 타입 검사: 서버 86개 파일·클라이언트 70개 파일 통과.
- `tests/forest-workshop-home-motion.browser.mjs`: 390×740 모바일 Chromium에서 실제 패키지 그림과 DOM을 사용하여 낮·밤 클래스, 태양/달 교체, 배경 밝기, 지역명 숨김(문구·접근성), 타이머에 의한 무터치 갱신, 반복 렌더 방지 확인. 기존 캐릭터 이동·모핑·게시판 입력·동작 줄이기 검사도 통과. 세계와 주민 데이터는 테스트 fixture이다.
- 실제 Open-Meteo 요청 성공: 서울 현지 `2026-11-04T01:00`, 8°C·흐림, 일출 `06:59`, 일몰 `17:31`, `Asia/Seoul` 응답 확인. 기기 위치를 요청하지 않았다.
- 0.7.1 공식 빌드, 카탈로그 lane·로케일·ZIP 내용/해시·릴리스 노트 검증 통과.

실제 Android 기기 및 정상 카탈로그 설치/업데이트 동선은 이번 검증에 포함하지 않았다. 낮·밤은 기존 그림의 조명 변화이며 별도 야간 배경 에셋은 추가하지 않았다. 저장소의 Issues 기능은 비활성화되어 별도 이슈 대신 PR에 작업 범위를 기록한다.
