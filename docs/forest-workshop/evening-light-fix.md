# 0.9.3 밤 배경 수정

기준 main 3fd7b12b4 (PR #31 병합). 낮/밤 판정 오류가 아니라 실제 배경 CSS 우선순위 문제였다. 연속 배경을 `.season-*.home-layout .column:has(...)`의 background shorthand로 그리는데, 이 선택자가 밤 background-color 규칙보다 강해서 색상을 transparent로 초기화했다. multiply만 남아 그림은 어두워지지 않았다. 기존 검사는 숨겨진 scene 이미지의 필터만 확인해 실제 표시 경로를 놓쳤다.

밤 선택자의 우선순위를 계절 배경과 맞춰 뒤에 선언된 밤 색상이 적용되도록 했다. 지역 시간·일몰과 기본 06~18시 판정, 주민 크기·이동·저장 데이터는 바꾸지 않았다.

검증: 실제 브라우저에서 수정 전 투명색 오류를 재현했고 수정 후 표시되는 column 배경색 rgb(153,153,153)와 multiply를 확인했다. 같은 실제 가을 WebP 배경의 낮/밤 스크린샷 평균 RGB 밝기는 140.6→89.2였다. `/tmp/fw-evening-day.png`, `/tmp/fw-evening-night.png`에 화면을 남겼다. 기존 home-motion의 지역별 낮/밤 전환·터치·모션 줄이기 검사도 통과했다. 변경 파일 포맷·린트 및 재생성 0.9.3 ZIP·카탈로그 무결성 검증 통과. 저비용 서브에이전트 한 명에게 경로 감사를 분담했다. 전체 게임 회귀와 타입 검사는 CSS 한 규칙 변경에 반복하지 않았다. Android 실기기는 미검증이다.
