# 0.9.5 홈 주민 이동 경로

기준: PR #33 병합 main 9f8d70a9c. 기존에는 모든 주민이 동일한 42초 경로를 공유하고 시작 시차만 달랐다. 여섯 표시 슬롯에 서로 다른 두 축의 폐곡선 경로를 적용한다. 각 주민의 크기와 설정된 지면 사각형, 42초 주기는 그대로이며 각 위치의 발 높이로 앞뒤 순서를 정하고 이동 방향에 따라 좌우 반전한다. 홈을 다시 방문할 때 기존의 무작위 주민 선택을 유지한다.

검증은 실제 브라우저에서 홈 주민 1~6명 크기·지면 경계, 여섯 경로의 동일 위상 좌표, 발 위치와 앞뒤 순서, 경로별 좌우 방향, 지면 편집 중 정지·모션 줄이기, 기존 인사·게시판 입력 및 지면 편집에 한정한다. 0.9.5 ZIP과 카탈로그는 빌더로 재생성해 해시를 확인한다. 전체 게임 회귀와 Android 실기기 검사는 이번 범위에 포함하지 않는다.
