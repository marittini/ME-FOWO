# 0.9.0 공방 운영·홈 배치 업데이트

기준 main: ffdea2abaa02f298ef65c66b22b62b09f0403d33 (PR #28 병합 이후).

요청: 창고 판매품의 생산 분야별 분류, 전 품목 공동 목표 재고, 초대권→골드 교환, 홈 주민 무작위 선택과 표시 인원 설정. 첨부 화면 기준으로 읽은 이야기의 세로 글자 줄바꿈, 주민 상세 프레임/초상/이름 배치와 항상 펼친 특기, 중복 무료 리필 버튼 제거, 홈 계절·날씨의 상단 이동·장면 확장·하단 동선 정리를 포함한다.

기본 가정: 공동 목표 재고는 모든 시설·품목의 공통 목표 수량 하나다. 교환은 초대권 1장당 100골드, 표시 인원은 1~6명으로 진행한다. 사용자 답변이 오면 반영한다. 이전 저장과 원문은 보존하며, 마이그레이션·서버 권위·중복 지급 방지·모바일 실제 화면 검증을 수행한다.

저비용 서브에이전트에 재화 교환·홈 주민·창고 분류·상세 배치를 나눠 맡기고 주 에이전트가 공동 재고와 홈 전체 레이아웃·통합 검증을 담당한다. Issues 비활성화로 PR과 문서에서 범위를 추적한다.
