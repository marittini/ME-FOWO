# Forest Workshop 0.9.0 — 공동 재고·창고 분류·홈 배치

기준 main: `ffdea2abaa02f298ef65c66b22b62b09f0403d33` (PR #28 병합 이후). 후속 PR #29. 검증일 2026-11-04.

## 요청과 적용

- 창고의 판매품을 전체/채집물/재배물/가공품/제작품/기타 재료로 나눈다. 재료는 가능한 경우 생산 시설의 분야로 분류하고 그 외 품목도 전체 또는 기타 재료에서 찾을 수 있다. 분류 변경 시 첫 페이지로 돌아가며 화살표는 해당 분류 안에서 넘긴다. 판매와 보호 재고 규칙은 유지한다.
- 모든 시설·품목의 **공동 목표 재고** 하나를 저장한다. 다른 품목이나 시설을 선택해도 같은 값이며 **전체 적용**으로 공통값만 바꿀 수 있다. **자동 생산**은 선택 제작품의 하위 재료를 켜고 다른 품목은 쉬게 하는 기존 제작 트리 기능이다.
- 초대권 상점의 리필/골드 교환 탭을 분리한다. 사용자가 확인한 환율은 초대권 1장당 100골드다. 1/10/100장 버튼으로 차감·지급을 명확히 표시한다. 서버는 1회 요청 1~10,000장의 정수, 잔액, 안전한 정수 범위와 중복 요청을 검증한다. 일일 제한·실제 결제는 없다. 상단 초대권 +도 납품 창이 아니라 상점을 열도록 연결하고, 초대 화면의 중복 리필 버튼은 없앴다.
- 홈은 첫 페어가 아닌 **영입된 전체 주민**에서 무작위로 뽑는다. 설정 → 표시에서 1~6명을 지정하며 이 기기에 저장된다. 같은 방문의 화면 갱신에서는 선택을 유지하고 새 방문이나 인원/영입 목록 변경 시 다시 뽑는다. 이름이나 그림을 바꾸면 현재 주민 레코드를 다시 읽어 반영한다. 이름표는 표시하지 않는다.
- 홈의 계절·날씨는 상단으로 이동하고 헤더가 장면을 가리지 않게 한다. 큰 보고 카드와 이야기 바로가기 대신 간략한 작업 보고, 같은 행의 미접속 시간/오늘의 납품 의뢰를 두어 장면을 넓혔다. 게시판은 세로·가로 화면의 카메라 경계 안에 두며 저장한 게시판 위치는 유지한다.
- 읽은 이야기의 **진행 중인 편의 재독 카드와 완결된 이야기 카드 모두** 제목을 전체 폭으로 두고 버튼을 아래에 배치한다. 긴 제목이 한 글자씩 세로로 흐르지 않게 한다.
- 주민 상세는 끈적임/음수 오프셋으로 헤더가 종이 프레임 밖에 나오던 배치를 수정한다. 긴 이름은 닫기 버튼 공간을 남겨 줄바꿈하고 초상을 키운다. 특기와 배치·돌파 설명은 토글 없이 항상 표시한다.

## 공동 재고와 이전 저장

저장 스키마 13 → 14에서 기존 개별 목표의 최댓값을 공동 목표로 채택한다. 진행 중 작업·켜짐·작업 순서·보호량·재고·재화·우편·이야기는 삭제하지 않는다. 이전 입력 객체도 변경하지 않는다. 새 패키지에서 저장한 스키마 14는 이전 패키지로 읽을 수 없으므로 다운그레이드 전에 백업해야 한다.

서버 생산 판단은 공통값을 사용하며 개별 규칙 요청으로 우회할 수 없다. 제작 트리는 수량을 단계마다 곱해 개별 목표로 저장하지 않는다. 공동 목표가 1이더라도 재료가 4개 필요한 제작법이 멈추지 않도록 **보호분 외에 제작 한 번분을 확보**한다. 자동 판매도 이 최소 재료를 남긴다. 이 보정은 품목별 사용자 목표가 아닌 제작 가능성을 위한 최소량이다. 실제 생산과 재료 소비를 시뮬레이션으로 확인한다.

## 분담과 검증

- 회귀 24개 스위트 통과. 공동 재고 이전/전체 적용/개별값 우회 거부/재료 최소량/보호/재시도, 골드 차감·지급/잘못된 입력/잔액 부족/정수 한도/중복 지급 방지 포함.
- 엄격 타입 검사: 서버 87개·클라이언트 73개 파일 통과. 포맷·린트 통과.
- 레이아웃 523건(14개 경로·104개 상태) 통과. 320×640 큰 글자, 390×844 16px, 긴 화면·가로·데스크톱에서 검증했다. 진행 중/완결 이야기의 긴 제목, 주민 프레임·큰 초상·항상 보이는 특기, 1명/6명 홈, 창고 분류, 골드 탭을 포함한다.

## 배경 추가 검수 — PR #29 후속 수정

0.9.0 첫 화면은 헤더/하단의 기본 배경과 가운데 장면의 공방 이미지를 따로 그렸다. 배치·클릭 테스트가 통과해도 서로 다른 그림이 가로로 끊기는 문제를 놓쳤다.

홈 전체 열의 배경에 계절별 공방 이미지를 한 번만 그리도록 수정했다. 헤더·주민 장면·하단 뒤에 같은 그림이 이어지고 가운데의 중복 이미지는 숨긴다. 기기 비율에 맞춰 원본 비율을 유지하는 cover 방식이며 이미지를 늘려 찌그러뜨리지 않는다. 야간에는 이 단일 배경에도 어두운 처리를 적용한다. 주민 위치, 헤더/하단 동선, 저장 좌표와 자원 규칙은 변경하지 않았다.

전체 홈 영역을 덮는 같은 이미지, 520px 데스크톱 열 폭, 중복 그림 숨김, 원래 이미지 노드 보존, 낮/밤 처리를 회귀에 추가했다. 523건 레이아웃과 보행·터치·지면 편집을 다시 검증하고 실제 엔진 화면을 재촬영했다. CPU가 바쁠 때 600ms 반응을 지나친 뒤 측정하던 테스트는 재터치와 측정을 같은 브라우저 작업에서 수행하도록 보완했다.
