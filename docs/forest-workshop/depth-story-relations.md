# 0.9.2 홈 깊이·탐험 연출·관계 초기화

기준은 PR #30 병합 main 99bef0c14. 홈 주민의 크기와 지면 범위를 유지하며 발 위치가 아래인 주민이 앞에 보이도록 한다. 보행 속도를 낮추고 반전 주기를 맞춘다. 탐험의 인원별 감정표현 위치를 캐릭터에 맞추고 사용 가능한 배경을 늘린다. 페어 등록 시 두 주민 프로필을 현재 관계 해석의 근거로 사용하며 기존 관계·게시된 이야기는 보존한다.

사용자 요청에 따라 저비용 서브에이전트 3명에게 홈, 탐험 표시, 관계 초기화를 분담한다. 검증은 변경된 홈 보행/겹침, 탐험 렌더/배경, 관계 초기화의 직접 회귀 및 배포 번들 무결성에 한정한다. 전체 게임 회귀·전체 화면 매트릭스는 반복하지 않는다. 실제 외부 모델과 Android 실기기 검증은 별도 수행하지 않았다.

구현 및 검증 결과는 완료 후 이 문서와 PR에 기록한다.
