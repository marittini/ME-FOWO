# 0.9.2 홈 깊이·탐험 연출·관계 초기화

기준은 PR #30 병합 main 99bef0c14. 홈 주민의 크기와 지면 범위를 유지하며 발 위치가 아래인 주민이 앞에 보이도록 한다. 보행 속도를 낮추고 반전 주기를 맞춘다. 탐험의 인원별 감정표현 위치를 캐릭터에 맞추고 사용 가능한 배경을 늘린다. 페어 등록 시 두 주민 프로필을 현재 관계 해석의 근거로 사용하며 기존 관계·게시된 이야기는 보존한다.

사용자 요청에 따라 저비용 서브에이전트 3명에게 홈, 탐험 표시, 관계 초기화를 분담한다. 검증은 변경된 홈 보행/겹침, 탐험 렌더/배경, 관계 초기화의 직접 회귀 및 배포 번들 무결성에 한정한다. 전체 게임 회귀·전체 화면 매트릭스는 반복하지 않는다. 실제 외부 모델과 Android 실기기 검증은 별도 수행하지 않았다.

## 구현 결과

- 홈: 동일한 발 위치 경로의 top과 z-index를 함께 보간한다. 낮은 발이 앞에 그려진다. 왕복 주기는 18초→42초이며 주민별 시차를 반전에도 전달하고 30% 경로 전환에서 방향을 바꾼다. 몸의 기존 보행 변형과 터치 반응은 유지한다. 편집 중 정지와 모션 줄이기에 반전도 함께 정지한다.
- 탐험: 감정표현을 그림 몸체 안에 두고 실제 화면에 그려진 높이(세로·가로 비율 및 배치 크기)를 기준으로 정렬한다. 숲길과 사계절 공방 외부 에셋을 기존 묶음에서 재사용해 배경 키를 4→9종으로 늘린다. 새 이미지 생성이나 원격 다운로드는 추가하지 않았다.
- 관계: 페어 저장 후 선택한 프로필 연결로 표준 프로필을 확인하고 이야기 연결로 짧은 현재 관계를 생성한다. 두 프로필에 명시된 기존 관계는 존중하고 없는 과거·연애를 만들지 않게 지시한다. 모델 응답은 JSON 검증 후 별도 initialRelationship에만 저장한다. 기존 친밀도·진행 중 이야기·최근 사건을 덮어쓰지 않는다. 실패 시 페어는 보존하고 재시도 버튼을 표시한다. 새 장 계획과 두 주민 장면에도 프로필에서 정리한 관계를 전달한다.
- 저장: 엄격한 pair 스키마에 필드를 추가하므로 v14→15 순차 이전을 추가한다. 업그레이드 후 저장은 이전 버전에서 열 수 없다. 기존 읽은 이야기와 에셋은 보존한다.

## 직접 검증

- home-cast 브라우저: 1~6명 크기·지면 경계 유지, 42초 주기, 두 위치에서 앞뒤 순서 교환, 주민별 반전 시차·방향, 편집 정지와 모션 줄이기 통과.
- home-motion 브라우저: 기존 보행·몸 변형·터치 반응 및 게시판 입력 우선 통과.
- reader 브라우저: 모바일 320px에서 1/2/3명, 세로·가로형 테스트 그림과 70/100/130% 배치, 실제 그림과 감정표현 경계·중앙 정렬 통과. 실제 숲길 WebP가 로드된 두 테스트 그림 화면을 /tmp/fw-depth-proof/reader-art.png에 남겨 확인했다. 테스트 그림이므로 실제 사용자 캐릭터 미리보기는 아니다.
- generated-experience 회귀: 서로 다른 표준 프로필 전달, 중복 호출 합치기, 잘못된 모델 응답의 무저장, 생성 중 페어 삭제 시 복원 금지, v14→15 이전 및 배경 키 검증 통과. 외부 모델 대신 응답을 제어한 어댑터를 사용했다.
- assets 회귀: 새 배경 키와 실제 포함 에셋 연결 통과.
- ME-personal 2.5.1 기반 해당 패키지 엄격 타입 검사(서버 88개·클라이언트 73개 파일), 변경 소스 포맷·린트 통과. 설치 번들과 카탈로그는 빌더로 재생성한다.

전체 게임 회귀·전체 화면 매트릭스는 실행하지 않았다. 실제 Engine 설치/업데이트, 외부 AI 모델 품질 및 Android 실기기는 이번 검증 범위 밖이다.
